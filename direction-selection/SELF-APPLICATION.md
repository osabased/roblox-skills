# Self-Application

Use this branch when direction selection evaluates changes to itself, another decision process, or a protocol that invokes this skill.

## Bound the meta-level

1. Name the actual target decision at the current meta-level.
2. Apply the proportional mode and protocol to that decision once.
3. After changing the target, verify intended behavior, contradictions, regressions, and newly introduced failure modes.
4. Correct each concrete defect and verify that correction.
5. Re-enter direction selection only when new material evidence changes the candidate set, ordered criteria, or a load-bearing assumption.

Protocol invocation, clause-by-clause validation, and verification of verification are not additional evidence. Additional passes require a concrete finding, new material evidence, or an explicit user requirement.

**Complete when:** self-application ends in a Direction Decision, a bounded Discovery Decision, an explicitly unresolved state, or finite correction of a concrete defect.
